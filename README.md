# Trip Lah! V1.0 — Preview

This is the isolated GitHub Pages preview for Trip Lah! V1.0 Stage A.

- Default landing screen: **All Trips**
- Select a trip to open its individual dashboard.
- This repository is separate from the production Travel Lah repository.
- Do not commit production secrets or private traveller data to this public preview repository.
- Stage A is a local-first multi-trip foundation. Multi-currency expense and shared-fund ledger features are planned for Stage B.

## Deployment
GitHub Pages publishes from the `main` branch, root folder.

## Acceptance
See `docs/STAGE-A5-PREVIEW-ACCEPTANCE.md`. The preview is not accepted until desktop, iPhone, iPad, offline, sync, and backup checks pass.
