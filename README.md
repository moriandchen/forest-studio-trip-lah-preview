# Trip Lah! V1.0 — Preview

Isolated GitHub Pages preview for Trip Lah! V1.0 Stage A.

- Default landing screen: **All Trips**.
- Select a trip to open its individual dashboard.
- Separate from the production Travel Lah repository.
- Do not commit production secrets or private traveller data here.
- Multi-currency expense and shared-fund ledger features are planned for Stage B.

GitHub Pages publishes from the `main` branch, root folder. See `docs/STAGE-A5-PREVIEW-ACCEPTANCE.md` for the acceptance checklist.
